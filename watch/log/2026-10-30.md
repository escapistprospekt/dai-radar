### Related, not yet tied to a tracked system

- **Forensics with partial C2PA Content Credentials** (arXiv
  2610.38639): uses partial credentials, which record only the last
  signer's edits, to rebuild those edits and adapt synthetic-image
  detectors to them. It is an application of C2PA, not a change to it.
  The Integrity, Trust and Opt-in rows in systems/c2pa.md are
  unaffected. Field: Content provenance for AI-generated media.
- **PCM: proof-carrying messages for multi-agent communication** (arXiv
  2610.39109): each claim in a message carries Merkle-log inclusion
  proofs from a signer the agent can't control. The authors' models of
  six deployed protocols, including uAgents, accept 504-712 of 712
  fabricated claims. This is about the trust placed in message
  content, not the keypair identity or Almanac discovery rows in
  systems/fetch-ai.md, so nothing there changes. The uAgents result
  comes from the authors' own model of the protocol and has not been
  checked against uAgents itself. Field: Decentralized AI agent /
  marketplace protocols.
- **DICE: blockchain-powered federated fine-tuning in Web3** (arXiv
  2610.39132): progressive training plus model-slice verification
  lets participants who can't host the full model take part. A
  tree-structured committee consensus and an incentive scheme let it
  scale to more data holders. Field: Decentralized incentive /
  consensus mechanisms for ML networks. No tracked system uses it.
- **Optimal privacy-budget allocation for DP-SGD** (arXiv 2610.39954):
  treats the per-iteration noise schedule as a control problem under a
  composed zCDP budget (PB-AMD) and proves that optimal schedules use
  up the whole budget. Field: Differential privacy for ML training. No
  tracked system uses it.
- **Rosemary: in-storage FHE acceleration** (arXiv 2610.38262): an FHE
  engine inside an SSD, aimed at the storage-I/O bottleneck. Encrypted
  deep-learning inference is one of the evaluated workloads, and the
  authors claim a 3.7x geometric-mean speedup over prior FHE
  accelerators. Field: FHE for ML. No tracked system uses it.
